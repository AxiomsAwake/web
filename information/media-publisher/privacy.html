Privacy Policy

This policy describes the private local AxiomsAwake Media Publisher and these public information pages.

Google and YouTube access

The publisher requests the Google OAuth scope https://www.googleapis.com/auth/youtube.force-ssl. This scope grants broader YouTube account permissions than the publisher’s current commands use. The current commands verify the operator’s channel, read channel, video and playlist information, upload a deliberately selected local video and its metadata, update the selected video’s visibility and embedding setting, and create a playlist with the selected visibility or add the video to an existing owned playlist.

The operator selects the file, title, description, credits, privacy setting and playlist. The tool verifies the authorized channel against the selected AxiomsAwake channel before saving authorization. Uploaded media and metadata are sent to Google’s YouTube APIs. YouTube stores and makes that content available according to the selected visibility and its own policies.

Local storage and use

Refresh credentials and signed resumable upload URLs are stored only in the local encrypted Secret Service credential store. Nonsecret publication journals are stored locally in the repository’s Git metadata directory. Journals record publication identity and progress, including file hashes, visibility, and video or playlist identifiers, so an interrupted upload can be resumed or reconciled.

The publisher uses Google APIs for authorization and YouTube operations. It does not sell Google user data, use it for advertising or profiling, or transfer it to other services. These public pages do not contain credentials, publication journals, recordings or private video identifiers.

Operator control and retention

The operator can revoke the tool’s access through Google Account permissions and manage or delete uploaded videos and playlists in YouTube Studio. Revoking access does not itself delete uploaded content or local journals. Local credentials and journals remain until the operator removes them using the local system’s controls. The publisher does not provide automatic data deletion.

This static website

These information pages use no analytics, cookies, JavaScript or external fonts. GitHub Pages hosts them and may process normal delivery metadata, such as a visitor’s IP address and request information, under the GitHub Privacy Statement. Google and YouTube handle data under the Google Privacy Policy.

Contact

For questions about the tool or these pages, open an issue in AxiomsAwake/web. Do not include credentials, authorization links or private media in a public issue.
