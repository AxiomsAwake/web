# Credits and research

**Direction and source material:** the repository owner, rmkn85, supplied the game brief, room choice and three reference photographs.

**New implementation:** original game code, procedural meshes, WebGL shaders, diagrams, interface, puzzle design and text were generated in ChatGPT for this project under the owner's direction. No claim is made that the owner manually authored the generated code, or that generated contributions necessarily qualify for copyright in every jurisdiction.

**Inspiration, not source assets:** *Crimson Room*, the point-and-click room escape game by Toshimitsu Takagi / Takagism. This project adopts the small-room observation → discovery → inventory → mechanism → escape loop. It is not a remake, sequel or affiliated product. No Crimson Room art, audio, character, dialogue, code or puzzle solution has been copied.

Research consulted 5 September 2026:

- [Crimson Room — overview](https://en.wikipedia.org/wiki/Crimson_Room): small-room first-person inspection, item discovery and escape-loop reference.
- [Crimson Room — MobyGames record](https://www.mobygames.com/game/84539/crimson-room/): reference-game context.
- [Create browser-based games — OpenAI](https://learn.chatgpt.com/use-cases/browser-games): the owner's requested workflow reference, emphasizing a defined plan, browser interaction tests and visual iteration.

**Dependencies and assets:** the release has no third-party runtime or build dependency, remote font, stock art, external audio, tracking pixel or API service. System fonts are selected by the browser; no font file is bundled. Web Audio effects and all visible art are generated locally. Playwright and Chromium are development/test tools only and are not distributed in the game.

The original photographs are not embedded in the deliverable or publicly uploaded. New architectural dimensions and unseen surfaces are explicitly marked as assumptions in `docs/RECONSTRUCTION.md`.


## Kitchen chapter correction (version 2)
The owner clarified that only detachable clutter should be removed. The kitchen chapter restores cabinetry, countertops, appliances and attached lighting and replaces the previous abstract puzzle chain with original food-preparation, cooking, baking and serving puzzles. Cabinet/appliance interiors are invented. No photographed person or household clutter is reproduced.
