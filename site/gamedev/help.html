A quick guide to exploring and changing the browser Studio.

Explore one change at a time.

Start with a playable world

Choose a world on the main page to open it directly, then follow its controls and objective. The page directory includes every current world and focused study. Use your browser’s Back button to return and choose another world, or open the full Studio and use its world selector.

Move between play and menus

Click the world to give it keyboard control. Press Esc or Tab, or click a menu or control, to leave play and release held movement. Buttons inside a world keep their own mouse and keyboard focus. In Last observatory, press I while playing to inspect the case file.

Edit a world

Choose Edit world, find a parameter, change it, then choose Apply & restart to activate your draft. Save draft and Load saved keep a draft in this browser. Export downloads a definition. To reopen it, choose Import / source, Open JSON file, then Load as draft. Review the draft before Apply & restart. The Studio world selector keeps applied settings for the current session. Save a draft before leaving the world page; opening another world from the web directory starts a new Studio session.

Try the presentation comparisons

Open the comparison suite, choose Living diorama, Wildlife, or Future laboratory, then pick Creature Motion, Action Feedback, Camera, or Environment / Lighting. The controls below belong to this focused suite.

Compare your candidate

Reference shows the starting presentation. Candidate contains your edits. Reduced turns down optional effects, and Stress shows a denser group. Replay resets the same seeded action so the comparison stays focused. Compact windows give the preview more room; choose Edit candidate to open the controls and Hide controls to return to inspection.

Try the controls

  • In Action Feedback, preview hit, miss, block, repair, command, or placement from the top of the controls. These cue previews leave the seeded simulation outcomes unchanged.
  • Change sliders and options to adjust timing, response, material roughness, light, framing, actor count, effects, sound, information, and reduced motion.
  • Drag the preview to orbit; use the camera menu for Showcase orbit, Overview, Follow, or Focus. Scroll over the preview to adjust framing.
  • Enable sound after a click or tap. The Audio cues switch controls whether events produce sound. Pause / resume freezes motion and sustained effects.
  • Save preset downloads bounded JSON. Reload preset opens a file picker for a saved preset. Restore reference discards the current edits.
  • Use Tab to move through controls and Space or Enter to activate them.

Inspect or adopt the native composition

The optional inspector shows copied simulation facts, event traces, resource counts and candidate parameters. The native source distribution includes a movement sandbox and an interaction range; each bundles the same pinned add-on, three settings, editable Resources, tests and source-specific rights. Source access is separate from this public browser application.

The runtime accepts copied snapshots through reconcile(snapshot), and identified events through present(event, recipe). Repeated event IDs reuse the same handle. A handle can update a sustained cue or cancel it; reset() and disposal release owned presentation. Rig paths, animation bindings and recipes belong to native Resources. The game retains movement destinations, damage and command outcomes.

Keep the claim in scope

The Studio illustrates a limited, deterministic fixture. It does not prove performance on physical devices, complete game behavior, or player acceptance.
