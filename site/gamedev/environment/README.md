# Scanned woodland soil

**Brown Mud Leaves 01** by Rob Tuytel, supplied by
[Poly Haven](https://polyhaven.com/a/brown_mud_leaves_01) under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Poly Haven's [asset license](https://polyhaven.com/license) permits reuse and
redistribution. This project retains attribution voluntarily.

The original 1K JPEG albedo, OpenGL normal and roughness maps are bundled without
image edits. Their downloaded sizes and upstream MD5s were checked; independent
SHA-256 pins and exact download URLs are retained in
[SOURCE.json](brown-mud-leaves-01/SOURCE.json) and the parent asset manifest.
The offline retrieval used the public API with a GameDev user agent. The game
does not call Poly Haven or require a service, account or key at runtime.

The native soil material uses world-space projection with a setting-authored
tile width and restrained normal/roughness response. This supplies actual
material structure, not proof that the fox's anatomy, the landscape or the
complete composition has achieved naturalism.

## Painted laboratory floor

**Concrete Floor Painted** by Rob Tuytel / [Poly Haven](https://polyhaven.com/a/concrete_floor_painted), **CC0-1.0** under the same license above. Original 1K albedo, OpenGL normal and roughness JPGs are retained unchanged. [SOURCE.json](concrete-floor-painted/SOURCE.json) pins exact source URLs, downloaded sizes, upstream MD5 and local SHA-256. The native floor material composes a restrained 2m world-space treatment; native room reflections supply lighting. No runtime external service is used.

## Captured woodland environment

**Nature Reserve Forest**, photography by Dimitrios Savva and processing by Jarod Guest / [Poly Haven](https://polyhaven.com/a/nature_reserve_forest), **CC0-1.0**. Original 2K Radiance HDR bytes are bundled unchanged. [SOURCE.json](nature-reserve-forest/SOURCE.json) pins bytes, SHA-256 and checked upstream MD5. Native PanoramaSkyMaterial supplies the distant environment and lighting; near terrain, water, banks and vegetation remain native geometry. An HDR panorama supplies no parallax and does not establish anatomical or scene-quality acceptance.

## Scanned woodland bark

**Bark Brown 01** by Rob Tuytel / [Poly Haven](https://polyhaven.com/a/bark_brown_01),
**CC0-1.0**. Original 1K albedo, OpenGL normal and roughness JPGs remain unchanged.
[SOURCE.json](bark-brown-01/SOURCE.json) pins source URLs, sizes, checked upstream
MD5 and SHA-256. Authored cylindrical UVs and native tangents keep the scanned
structure aligned along each branch. Native mipmaps bound distant texture detail.
