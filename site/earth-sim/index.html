What this model is—and is not

This is a conceptual cellular automaton, not a physical weather forecast. Local rules couple terrain, heat, wind, clouds, rain, and urban pollution to expose emergent behavior and tipping under sustained stress.

The browser version preserves the 2012 rule set and visual encodings, makes the historical scan order deterministic, and restores elevation—the one assignment element the original report explicitly left out.
