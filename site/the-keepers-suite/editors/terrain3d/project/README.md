# Native terrain project

This is an editable Godot/Terrain3D project, not a height-only export. The scenes, texture and material resources, control maps, terrain regions, mesh assets and instance placements remain native data.

Open it in its matching full browser editor, or on Windows/Linux run `python setup_native.py` (`py setup_native.py` on Windows) and open `project.godot` with Godot 4.7.2. Setup adds only the verified upstream native libraries; it does not overwrite authored data or plugin source. Keep the complete project in Git or retain its ZIP. Do not commit `.godot/` import caches.

Terrain3D is upstream 1.0.2 with its MIT notice in `addons/terrain_3d/LICENSE.txt`. The starter terrain, noise-based textures and simple rock mesh are generated by `generate.gd`; rerunning that script on an existing world is refused. Replace them or add your own assets using the full upstream editor. The project-exchange plugin only exports the complete master and supplies read-only acceptance observations.

Only open projects you trust: Godot tool scripts execute code. Matching editor dependencies are validated before browser import; arbitrary authored scripts remain your responsibility.
