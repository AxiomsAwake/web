# Complete upstream editor

Godot source: https://github.com/godotengine/godot/tree/ed1daf0bf001b61586d9930840f2f1394092c079

Terrain3D 1.0.2 source: https://github.com/TokisanGames/Terrain3D/tree/v1.0.2-stable

The Terrain3D toolbar, settings, asset dock and operations are upstream code. Audited browser-platform build adjustments are identified in editor-build.json. All applicable notices are retained in legal/. Download the native project to preserve scenes, materials, region maps, mesh assets and placements.

For Windows/Linux native editing, extract the project ZIP, run `python setup_native.py` (`py setup_native.py` on Windows), and open `project.godot` in Godot 4.7.2. Only verified native libraries are added.
