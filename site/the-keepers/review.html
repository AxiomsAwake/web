# The Keepers 0.10.0-demo.3 — internal tester build

This is a development snapshot of the reconstructed Player, published for feedback while work toward stable 0.10.0 continues. It is not the completed stable game or full immersive campaign.

Earlier build attempts exposed a missing pinned checker and a test fixture inheriting the production publishing mode. Those delivery prerequisites are corrected; the selected Player and gameplay are unchanged.

## What is in this build

- The current qualified reconstructed Player and its exact provider packages.
- Authoritative command admission and explanations, with the existing force-order, recovery, replay and session controls.
- Shared GameDev static presentation batching, reused through View, Product, Recording and Player.
- Complete native Player qualification: all 26 owners, 4,620 assertions, zero failures. This does not establish ordinary browser gameplay acceptance.

## Please try

Enter a battle, give orders to different forces, exercise withdrawal/replacement/Resume, and try save, return and recording controls. Report confusing controls, missing feedback, broken continuity and performance problems together with the build identity shown on this page.

## Work still in progress

The newer shared authored-definition/scenario lifecycle has passed Product native checks and is still being integrated into Recording and Player. It is not part of this selected Player build. Full E1/Web journeys, campaign completeness, appearance and motion, device/input/accessibility coverage, physical capacity/performance and human acceptance remain open. Historical 0.8 saves remain with their archived player.

Future tester demos reuse this Web-only pipeline. Stable releases retain their separate full acceptance and platform requirements.
